# Switzer

Switzer is designed by Swiss Typefaces and distributed free for personal and
commercial use via [Fontshare](https://www.fontshare.com/fonts/switzer)
(Indian Type Foundry). These WOFF2 files were downloaded from Fontshare's CDN
on 2026-10-05 and are self-hosted here via `next/font/local` instead of
loading from Fontshare's CSS API at runtime.

Verify current terms at fontshare.com before any commercial redistribution
of the font files themselves (as opposed to using them in this product).
